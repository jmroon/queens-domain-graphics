Each download now includes a short **INSTALL.txt written specifically for that package**. Full settings, compatibility, and troubleshooting information remains on the mod page.

**No mod, loader, graphics, or saved-setting changes. Existing users do not need to update.** Standalone still includes stable UE4SS 3.0.1; Mod-only supports either existing UE4SS folder layout.

- **Standalone:** extract beside `QueensDomain.exe`. Use only if UE4SS is not already installed.
- **Mod-only:** copy the files inside `PAKs` to `QueensDomain/Content/Paks`, then copy `QDGraphics` to your active UE4SS `Mods` folder. Both flat and nested paths are listed in its INSTALL.txt.
